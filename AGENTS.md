# Agent context

For worker workflow or pipeline changes, first read the canonical
[workflow documentation standard](docs/fleet/workflow-standard.md), then the
worker's current guide and linked implementation. Keep source, deployment and
benchmark evidence distinct. Update diagrams and contracts in the same PR as
behavior changes. Apply [improvement scopes](docs/fleet/improvement-scopes.md)
for matched visual comparisons, Android rendering, generation timing,
regression checks and upstream dependency reviews. See [CLAUDE.md](CLAUDE.md)
for SDK development commands and
[Fleet HQ](docs/fleet/README.md) for fleet configuration and runbooks.
